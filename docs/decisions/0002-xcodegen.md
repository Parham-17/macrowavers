# 2. The Xcode project is generated with XcodeGen

Date: 2026-09-29. Status: accepted.

## Context

`.pbxproj` merge conflicts are the most common way small iOS teams lose an afternoon. Three developers adding files
in parallel on feature branches would hit them weekly.

## Decision

`project.yml` is committed; `SkyAndPlanets.xcodeproj` is generated by XcodeGen, gitignored and refused by the
pre-commit hook. Per-developer settings (signing team) live in a gitignored `Configs/Local.xcconfig`.

## Consequences

- No project-file conflicts. Adding files needs `make generate`, which everyone learns on day one.
- Target and setting changes are reviewable as a small YAML diff.
- Tools that write into the `.xcodeproj` (Reality Composer Pro 3's linked-project mode, some SPM flows) lose their
  edits on regeneration. The default RCP hand-off is therefore `.reality` exports into `Resources/`; anything
  that must live in the project goes into `project.yml`.
- XcodeGen must exist on the CI runner (installed by the workflow or by bootstrap on the self-hosted Mac).
